Ranga — Política de privacidade

Atualizada em 31 de outubro de 2026.

O Ranga é um navegador para Linux baseado no Helium e no Chromium. Esta página explica o que acontece com os seus dados quando você liga a sincronização com uma conta Google.

A sincronização é opcional

Sem conectar uma conta, nada sai do seu computador por causa do Ranga. A sincronização só começa quando você clica em "Conectar" nas configurações.

O que o Ranga acessa na sua conta Google

  • Pasta de dados do app no seu Google Drive (drive.appdata): uma pasta escondida que só o Ranga enxerga. O Ranga não vê nem mexe em nenhum outro arquivo do seu Drive.
  • Seu endereço de e-mail, só para mostrar nas configurações qual conta está conectada.

O que é guardado e como

Favoritos, abas abertas, histórico recente, grupos, espaços que você marcar para sincronizar e a lista de extensões instaladas. Tudo é cifrado no seu computador (AES-256-GCM) antes de ir para o Drive, com uma chave que só você tem: a chave de recuperação mostrada ao ativar. Nem o Google, nem o autor do Ranga conseguem ler esses dados.

Senhas não são sincronizadas.

Com quem os dados são compartilhados

Com ninguém. Não há servidor do Ranga: os dados vão direto do navegador para o seu Drive. O Ranga não usa os dados para publicidade, não vende nem repassa nada a terceiros e não usa os dados para treinar modelos de IA.

Como apagar

Em Configurações → Sincronização → Desconectar, o Ranga apaga do Drive os arquivos deste aparelho e esquece a chave. Para apagar tudo, no Google Drive abra Configurações → Gerenciar apps → Ranga → Opções → Excluir dados ocultos do app, e remova o acesso do Ranga em myaccount.google.com/permissions.

Uso de dados das APIs do Google

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
